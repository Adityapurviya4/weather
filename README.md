This is a weather forecast app built using HTML, CSS, JavaScript, and React. It uses a Weather API to show real-time weather information such as current temperature, weather condition, humidity, air quality, sunrise & sunset time, and a 5-day forecast. Users can search for any city and view accurate updated weather data in a clean and responsive UI
