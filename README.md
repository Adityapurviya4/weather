# ☁️ SkyCast: Real-Time Weather Dashboard

## 🌟 Overview
SkyCast is a modern weather forecasting application that provides users with accurate, real-time atmospheric data for any city worldwide. Built with **React**, it transforms complex API data into a clean, intuitive, and mobile-responsive interface.

## ✨ Key Features
* **Global Search:** Instant weather updates for any city or region.
* **Real-Time Metrics:** Current temperature, humidity, and weather conditions.
* **Health & Environment:** Integrated **Air Quality Index (AQI)** monitoring.
* **Astronomy Data:** Precise sunrise and sunset times.
* **Extended Forecast:** Comprehensive 5-day weather outlook.
* **Responsive Design:** Fully optimized for desktop, tablet, and mobile viewing.

## 🛠️ Tech Stack
* **Frontend:** React.js, HTML5, CSS3
* **Logic:** JavaScript (ES6+), Fetch API
* **Data Source:** [OpenWeatherMap API](https://openweathermap.org/api) (or your specific API)
* **Styling:** CSS Modules / Styled Components
